# Egypt Hero

## Run it

1. Open this folder in VS Code.
2. Open a terminal in VS Code (Terminal > New Terminal).
3. Install dependencies:
   npm install
4. Start the dev server:
   npm run dev
5. Open the URL it prints (usually http://localhost:3000).

## Replace the placeholder images

`public/images/pyramids.jpg` and `public/images/pyramids-thumb.jpg` are plain
gradient placeholders so the layout runs immediately. Swap in your own real
photos using the exact same filenames, or update the paths in
`components/HeroSection.jsx`.
